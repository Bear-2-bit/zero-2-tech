# 从0到1

## 我现在正在训练全栈开发+部署上线的能力，你需要带我从0到1跑通整个流程。我想实现一个麻雀虽小但五脏俱全的一个网站，能够极大的训练自己的工程化的能力。开发阶段：前端采用Vue3实现，后端采用FastAPI，需要简单AI功能(比如调用Deepseek API)，需要简单数据库(SQLite)；部署阶段：采用阿里云2核2G的Ubuntu24.04轻量化服务器，Git和Github管理程序本地仓库和远程仓库，Nginx实现服务器反向代理。


# zero-2-tech

一个用于训练完整全栈开发与部署流程的 AI 学习任务管理项目。

## Tech Stack

- Frontend: Vue 3 + Vite
- Backend: FastAPI
- Database: SQLite
- AI: DeepSeek API
- Deployment: Ubuntu 24.04 + Nginx
